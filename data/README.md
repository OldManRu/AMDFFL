# Canonical League Data

This folder is the source of truth for AMD FFL historical data.

Principles:
- Franchises are persistent league slots.
- Team identities may change over time.
- Owners are modeled separately from team identities.
- Season files contain source results for a single season.
- Career totals, rankings, records, droughts, and championship counts should be derived whenever possible.
- Questionable historical values are preserved until verified rather than silently corrected.
